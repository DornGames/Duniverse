# Duniverse 项目发布说明

本文介绍 GitHub 上 `main` 分支中的地图与数据。GitHub 最新的正式版本标记是 [v0.3.1](https://github.com/DornGames/Duniverse/releases/tag/v0.3.1)，于 2026-11-11 发布。本文是项目导览，不创建或替代正式版本；`main` 可能包含该标签发布后的更新。

## 项目是什么

Duniverse 围绕虚构世界《𣿅国行政区划图》制作地图浏览器，并把地图中的边界、海岸、水系、地名和地形整理为可单独查看的数据层。

项目同时保存提取脚本、矢量数据、人工修订记录和模型说明，方便读者追踪地图要素的来源和处理过程。

## 打开地图后可以做什么

- 缩放和平移地图，按中文名、𣿅语名、行政区编号或城市邮政区号搜索地点。
- 查看国家、大区、省份、城市、山峰和已命名河流的可用资料。
- 单独显示行政区边界、海岸线、河流、运河、城市、道路、高铁车站、海底深度和地形晕渲等图层。
- 点击大区或省份查看预先计算的平均海拔和极值；右键陆地查看模型海拔，点击海洋查看模型水深。

地图操作入口：[在线地图](https://dorngames.github.io/Duniverse/)。

## 项目具体做了哪些工作

### 把地图拆成可编辑的几何图层

项目从行政区划图中整理行政区面、国境、海岸线、邻国边界、河流、运河、湖泊和城市标记。主要数据保存在 `data/`，格式包括 GeoJSON、JavaScript 和 JSON。图像提取脚本及首轮结果见[特征提取报告](../FEATURE_EXTRACTION_REPORT.md)。

### 留下几何复核过程

海岸线和河网经过局部复核与修订。仓库保留修正批次、审阅图片、审核脚本和相关记录，让读者能查看修改依据。这些材料记录指定区域的复核方式和处理结果。其他图层或未审阅区域的精度不能据此推定。

### 添加地形和地图查询

陆地地形使用固定种子生成，并参考地图标注的山峰、河流、海岸和城市位置。海底深度依据海岸线和岛链形状生成。地图还可以搜索地名，并查询大区、省份和地图点位的模型数值。

这些数值服务于这张虚构地图的表达。它们不是对真实行星地表的测量。

### 建立项目专用坐标参考

原图没有经纬网或比例尺，项目因此根据给定国土面积建立自定义的土星地图坐标参考。地图文件仍保留原图像素坐标；转换结果使用项目定义的坐标标识，不等同于 WGS 84、EPSG:4326 或土星官方坐标。

测绘假设、公式和误差边界见[地图测绘报告](../saturn-map-survey-report.md)。

## 如何理解地图上的数字

地图上的省界和河流位置用于展示这张虚构地图，不能当作权威 GIS 边界。海拔、海底深度、行政区面积和高速里程都依赖项目设定、图像几何或模型计算。它们不是实测数据，使用时应保留这一层限定。

逐项口径见[数据、坐标与精度边界](DATA_AND_LIMITS.md)。
