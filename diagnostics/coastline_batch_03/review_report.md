## 红线拟合警示复核

图中的红线是当前矢量边界，青色线是高分辨率黑色岸线笔画骨架。像素中心索引到 12× 参考图像素中心的换算为 `X12 = 12x + 5.5`、`Y12 = 12y + 5.5`；对应像素边缘坐标为 `12(x + 0.5)`、`12(y + 0.5)`。开放海岸线来源按 `-11/24` 像素归一化，其他来源按 `-0.5` 像素归一化。

用户截图所示的 SHORE-GAP-0002、0003、0005 局部样本中，矢量线到黑色岸线笔画的距离中位数为 `2.0` 个参考图像素，95 百分位为 `3.597` 个参考图像素，即 `0.2997` 个底图像素；到笔画骨架的 95 百分位距离为 `10.788` 个参考图像素，即 `0.899` 个底图像素。以 2 像素步长在 ±12 个参考像素范围内搜索平移，最佳平移为 `(0, 0)`。

因此，局部测量未支持整体平移红线。红线表示水陆边界，黑色笔画有明显宽度，笔画骨架并不等同于水陆边界；截图中可见的边缘差异需要结合这点判断。以上数字只覆盖这三个局部候选区域，不代表全图拟合精度。测量脚本、数值表和叠加图分别见 [`check_stroke_fit.py`](check_stroke_fit.py)、[`coastline_stroke_fit_metrics.csv`](coastline_stroke_fit_metrics.csv) 和 [`coastline_stroke_centerline_review.png`](coastline_stroke_centerline_review.png)。

对 SHORE-GAP-0002 `(1597.7885, 443.6394)`、SHORE-GAP-0003 `(1610.0250, 445.4000)`、SHORE-GAP-0005 `(1596.3015, 446.7279)` 的原始候选框，在 no-river 和 no-text 两份参考图的海洋连通水域掩膜中均检测到 0 个边界像素。因此它们不构成可确认的缺失海岸线；红线偏差不能据此通过加线或移线解决。
